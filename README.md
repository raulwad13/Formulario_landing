# Formulario landing

Página HTML de práctica de maquetación y formularios.

## Tecnologías

HTML.

## Cómo empezar

Abre `index.html` en un navegador.

## Estructura y notas

`index.html` contiene la página; no requiere instalación ni servidor backend.

## Objetivo

Repositorio educativo para practicar y afianzar conceptos. No se presenta como una aplicación de producción.
